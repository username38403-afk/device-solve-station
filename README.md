# Tech Resolve

# MASTER PROMPT — BUILD A PRODUCTION-READY “FIXMYTECH” PLATFORM

Build a fully functional, production-quality, enterprise/MNC-level responsive web platform called “FixMyTech” — an all-in-one consumer technology troubleshooting, diagnostics, privacy, security, and utility platform.

Product philosophy:

“Having a tech problem? Test it. Understand it. Fix it.”

Do NOT create a simple landing page, static mockup, or fake demo. Build a complete functional web application with real interactions, proper validation, responsive layouts, accessibility, performance optimization, security, scalable architecture, professional UX, loading states, error handling, empty states, permissions handling, and graceful fallbacks.

4. Scan QR code from second device.

5. Establish secure connection.

6. Select files.

7. Transfer.

8. Display progress.

9. Confirm completion.

Show:

- Connection status

- File size

- Progress

- Remaining time

- Cancel

- Retry
